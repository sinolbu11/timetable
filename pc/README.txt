내 시간표 · 트레이 앱 사용법
==============================

설치는 필요 없어요. 작업 표시줄 오른쪽(시계 옆)에 아이콘으로 떠 있다가,
누르면 오늘 내 수업과 이번 주 변동만 작은 창으로 보여줘요.
선생님마다 다른 "개인 코드"로 본인을 확인해서, 자기 시간표만 볼 수 있어요.

---------------------------------------------
[수업계 선생님] 나눠 주기 전에 한 번만
---------------------------------------------
1. 시트에 새 코드를 붙이고 저장 → 시간표 관리 → 처음 설정하기
   교사 탭에 "개인 코드 (자동)" 칸이 생기고 선생님마다 8자리 코드가 만들어져요.
2. Apps Script → 배포 → 새 배포 → 웹 앱
   - 설명: PC 앱용 / 실행 사용자: 나 / 액세스 권한: 모든 사용자 → 배포 → 주소 복사
   - (선생님용 "내 시간표" 링크와는 다른, PC 앱 전용 주소예요)
3. 복사한 주소를
   - 설정 탭의 "PC 앱 주소" 칸에 넣고,
   - timetable_tray.ps1 을 메모장으로 열어 맨 위 $PresetDataUrl = '' 의 따옴표 안에 넣고 저장해요.
4. 교사 탭의 학교 메일을 확인한 뒤 시간표 관리 → 선생님 개인 코드 메일 보내기
   각 선생님께 자기 개인 코드가 학교 메일로 가요.
5. 이 폴더(파일 4개)를 선생님들께 나눠 드려요. 파일에는 개인 코드가 들어 있지 않아서 함께 써도 돼요.

※ 코드가 새어 나갔다면: 교사 탭에서 그 선생님의 개인 코드 칸을 지우고 4번을 다시 하면 새 코드가 만들어져요.
※ 공용 "읽기 키"는 관리용이에요. 선생님들께 나눠 주지 마세요.

---------------------------------------------
[선생님] 처음 한 번
---------------------------------------------
1. 폴더를 바탕화면이나 문서 폴더에 두고 "내 시간표 실행.vbs"를 더블클릭해요. (창 없이 바로 아이콘만 생겨요)
2. 설정 창에 학교 메일로 받은 개인 코드를 넣고 [확인] → "○○ 선생님으로 확인됐어요"가 나오면
   "윈도우를 켤 때 자동으로 실행"을 체크하고 저장해요.
3. 작업 표시줄 오른쪽에 시간표 아이콘이 생겨요.
   아이콘이 ^ 버튼 안에 숨어 있으면, 끌어서 작업 표시줄로 꺼내 두세요.

---------------------------------------------
[매일]
---------------------------------------------
- 아이콘 클릭: 오늘 내 수업(1~7교시)과 이번 주 나와 관련된 변동이 보여요.
  주황 = 새로 들어가는 수업, 회색 줄 = 빠진 수업, 빨강 = 수업계 확인 중
- 다른 곳을 누르면 창이 닫혀요. 계속 띄워 두려면 "창 고정"을 체크해요.
- 맨 위 파란 칸에 "지금 몇 교시 / 다음 수업"이 나와요. 아이콘에 마우스만 올려도 다음 수업이 보여요.
- 내가 들어가는 변동 옆 [확인했어요]를 누르면 수업계에 확인했다고 전달돼요.
- 알림은 화면 가운데 "사라지지 않는 창"으로 떠요. [확인했어요]를 누르거나 [나중에]를 눌러야 닫혀요.
  · 아침에 컴퓨터를 켰을 때: 오늘 바뀐 수업 + 아직 확인 안 한 변동
  · 수업계가 시간표를 바꿨을 때: 새 변동 (꺼져 있는 동안 생긴 것도 켜자마자)
- 확인 안 한 변동은 그 수업 1시간 전과 다음 날 아침에 다시 알려 줘요. 아이콘에는 주황 점이 남아요.
  오른쪽 클릭 → "확인 안 한 변동 보기"로 언제든 다시 볼 수 있어요.
- 설정에서 고를 수 있는 것
  · 알림 소리: 창이 뜰 때 소리 (기본: 끔)
  · 바뀐 수업 시작 전 미리 알림: 내가 들어가는 바뀐 수업 10분 전 (5·10·15·30분, 안 함)
  · 퇴근 전 다음 날 요약: 내일(금요일이면 월요일) 바뀐 수업 (기본: 켬, 16:30 이후)
- 변동 목록은 오늘부터 다음 주 금요일까지 보여요.
- 담임 선생님은 팝업에 "오늘 우리 반" 바뀐 수업이 보이고, 아침에 한 번 알림이 떠요. (교사 탭 담임 반 기준)

---------------------------------------------
[관리자 · 교장 · 교감]
---------------------------------------------
- 교사 탭에 이름·학교 메일을 넣고 담당 과목에 "교장" 또는 "교감"이라고 적으면 관리자로 알아봐요.
  (설정 탭 "관리자 메일"에 적힌 선생님과 시트 주인도 관리자예요.)
- 개인 코드는 다른 선생님과 똑같이 교사 탭 E열의 본인 코드를 넣어요.
- 팝업 맨 위에 "학교 전체 · 오늘": 오늘 바뀐 수업 목록, 이번 주 건수, 선생님 미확인, 확인 필요, 나이스 미반영.
- [학교 전체 보기]를 누르면 웹 화면의 학교 전체 탭이 바로 열려요.
- 아침에 처음 켜면 "오늘 학교 변동 n건 · 미확인 n건" 알림이 한 번 떠요.
- 수업이 없는 분(교장·교감)은 학교 요약만 보여요.
- 새 변동이 생기면 알림이 뜨고 아이콘에 주황 점이 생겨요.
- 수업 시간(평일 7:00~18:30)에는 10분마다, 그 밖에는 1시간마다 확인해요.
- 오른쪽 클릭: 주간 시간표 열기(학교 계정 화면), 새로고침, 설정, 종료

---------------------------------------------
[업데이트]
---------------------------------------------
- 새 버전이 나오면 프로그램이 스스로 내려받아 바꾸고 조용히 다시 시작해요. (켤 때와 하루 한 번 확인)
  설정에서 "새 버전이 나오면 자동으로 업데이트"를 끌 수 있고, 오른쪽 클릭 → "업데이트 확인"으로 바로 확인할 수 있어요.
- 수업계가 "업데이트.bat"을 보내 주면 더블클릭 한 번으로 종료 → 새 파일 → 다시 실행까지 돼요.
  처음 쓰는 PC에서도 같은 파일로 설치돼요. (문서\내 시간표 폴더에 설치)
- 예전 파일은 timetable_tray.ps1.bak 으로 남아요.

[수업계: 새 버전 올리기]
- 깃허브 timetable 저장소의 pc 폴더에 timetable_tray.ps1 과 version.txt 를 올리면 끝이에요.
  (모바일 앱 파일 올리는 것과 같은 방법. 1~2분 뒤부터 선생님 PC에 반영)

[저장 위치]
설정은 %APPDATA%\SchoolTimetable\tray.json 에만 저장되고, 개인 코드는 내 Windows 계정으로 암호화돼요.
